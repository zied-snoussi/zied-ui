# Colors

All colors are CSS variables defined in `theme.css` (`:root` for light, `.dark` for dark) and exposed to Tailwind through `@theme inline`, so you write `bg-primary`, `text-muted-foreground`, `border-border`, and so on. Swatches show **light / dark**.

## Radius

`--radius: 0.75rem`. Tailwind exposes `rounded-sm` (radius − 4px), `rounded-md` (− 2px), `rounded-lg` (radius), `rounded-xl` (+ 4px), up to `rounded-4xl` (+ 16px).
