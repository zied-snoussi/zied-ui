MCP server

Zied UI · Storybook MCP

Public Model Context Protocol server for the @zied-snoussi/ui component library. AI agents use it to read the components, props, stories and docs of the published Storybook before writing code.

Endpoint

https://zied-ui-mcp.vercel.app/mcp

Streamable HTTP transport. This page is for humans; agents connect to /mcp.

Add it to your agent

Claude Code:

claude mcp add --transport http zied-ui https://zied-ui-mcp.vercel.app/mcp

Cursor (.cursor/mcp.json) or VS Code (.vscode/mcp.json, key servers):

{
  "mcpServers": {
    "zied-ui": { "url": "https://zied-ui-mcp.vercel.app/mcp" }
  }
}

Tools

docs-listList every component and docs page.
docs-showProps, stories and usage of one component.
docs-show-storyOne story with its args and code.
